Prefill

Process the prompt in parallel. For long inputs, time to first token can dominate user-perceived latency.

Decode

Generate tokens incrementally, with KV-cache capacity shaping effective concurrent request count.

Continuous batching

Admit and retire requests as generation proceeds, improving GPU utilization over fixed batches.

Serving trade-offs

Latency, throughput, model quality, and cost form a multi-objective engineering problem. Track TTFT, token generation latency, requests per second, memory headroom and tail latency—not just peak FLOPS.
